# 美元支付平台对接方案（预留）

> 版本：v1.0
> 所属项目：《项目设计方案.md》阶段二（财务在线结算）
> 目标：预留对接国内主流国际物流美元结算平台——**美元快付**、**荣易达（荣e通）**，实现海运费等美元应收的在线支付结算

---

## 1. 背景与目标

货代行业跨境结算痛点：海运费以美元计，企业间结汇手续繁琐、跨境结算难、对账慢。主流美元结算平台（美元快付、荣e通）通过"**平台 + 银行**"两级在线发票审核，实现美元在线支付。

本项目**预留对接能力**，使系统在财务模块可发起美元在线收款/支付，并同步结算状态。

### 目标平台
| 平台 | 运营方 | 特点 |
|------|--------|------|
| **美元快付** | 锦程物流网 | 面向货代/物流企业，两级在线发票审核，海运费在线支付 |
| **荣e通** | 荣易达(cargonpay.com) | 国内唯一国际物流第三方结算平台，人民币/美元在线支付，已接中行/浦发 |

## 2. 对接设计思路

### 2.1 复用现有集成适配器架构
系统已有统一适配器框架（[integrations/index.js](file:///c:/Users/im/Desktop/新建文件夹/freight-system/backend/src/integrations/index.js)），统一 `send()/query()` 接口，通过 `IntegrationConfig` 表动态配置。美元支付对接**沿用此模式**，新增适配器即可。

### 2.2 新增适配器
| 适配器 code | 名称 | 用途 |
|-------------|------|------|
| `usd_pay_fast` | 美元快付 | 发起美元支付、查询支付状态 |
| `rong_yida` | 荣e通结算 | 发起美元/人民币支付、电子发票、对账 |

### 2.3 adapter 文件示例（`src/integrations/adapters/usdPay.js`）
```js
// 美元支付平台对接适配器（预留）
// 负责美元在线支付发起、状态查询、电子发票、对账同步。
// 真实环境按平台 API 文档实现签名与加解密。
const axios = require('axios');
const crypto = require('crypto');

const code = 'usd_pay';

function sign(cfg, payload) {
  // 按平台约定拼接 + 私钥签名（示例：HMAC-SHA256）
  const raw = cfg.appKey + JSON.stringify(payload) + cfg.secret;
  return crypto.createHmac('sha256', cfg.secret).update(raw).digest('hex');
}

async function call(cfg, payload, action) {
  const url = `${cfg.baseUrl || ''}/api/${action}`;
  const headers = {
    'Content-Type': 'application/json',
    'X-App-Key': cfg.appKey,
    'X-Sign': sign(cfg, payload),   // 预留签名
    'X-Timestamp': Date.now(),
  };
  if (cfg.apiKey) headers['X-API-Key'] = cfg.apiKey;
  const resp = await axios.post(url, payload, { headers, timeout: 8000 });
  return resp.data;
}

async function send(cfg, payload) {
  return call(cfg, payload, 'pay');       // 发起支付
}

async function query(cfg, payload) {
  return call(cfg, payload, 'status');    // 查询支付状态
}

module.exports = { code, name: '美元支付平台', send, query };
```

## 3. 数据模型支持

### 3.1 充值/支付记录（可选新增）
在 `FinanceRecord` 之上增加支付平台流水记录，用于追踪第三方支付状态：

```js
const PaymentTransaction = sequelize.define('PaymentTransaction', {
  id: { type: DataTypes.INTEGER, primaryKey: true, autoIncrement: true },
  financeId: { type: DataTypes.INTEGER },        // 关联财务流水
  platformCode: { type: DataTypes.STRING(30) },  // usd_pay_fast / rong_yida
  platformTxNo: { type: DataTypes.STRING(64) },  // 平台交易号
  direction: { type: DataTypes.ENUM('collect', 'pay') }, // 收款/付款
  amount: { type: DataTypes.DECIMAL(15, 2) },
  currency: { type: DataTypes.STRING(10), defaultValue: 'USD' },
  status: { type: DataTypes.ENUM('init', 'processing', 'success', 'failed', 'refunded'), defaultValue: 'init' },
  rawResponse: { type: DataTypes.TEXT },         // 平台原始回执
}, { timestamps: true });
```

## 4. 接口设计

### 4.1 对外提供的业务接口（`/api/payments`，阶段二新增）
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /payments/initiate | 发起支付（选平台、传入财务流水） |
| GET | /payments/:txNo | 查询支付状态 |
| POST | /payments/:txNo/callback | **平台回调**（支付结果通知） |
| GET | /payments/platforms | 可用支付平台列表 |

### 4.2 回调处理关键点
- **验签**：回调需验签，防止伪造（按平台密钥）。
- **幂等**：同一平台交易号只更新一次状态。
- **状态同步**：`success` 时更新对应 `FinanceRecord` 的 `paidAmount/status/paidAt`。

## 5. 安全与合规要点

| 项 | 要求 |
|----|------|
| 签名 | 所有请求携带签名（HMAC/私钥），时间戳防重放 |
| 密钥 | appKey/secret 存 `IntegrationConfig.config`（加密存储），不入代码库 |
| 回调 | 验签 + IP 白名单 + HTTPS |
| 幂等 | 回调/查询需幂等处理 |
| 金额 | DECIMAL 精度，避免浮点误差 |
| 合规 | 跨境结算遵循外汇管理规定，平台合规兜底 |
