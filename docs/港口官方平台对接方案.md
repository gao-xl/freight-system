# 港口官方平台对接方案（青岛/上海/宁波等）

> 版本：v1.0
> 所属项目：《项目设计方案.md》阶段二（港口对接）
> 目标：对接国内主要港口的**官方 EDI/数据平台**，获取船舶动态、集装箱状态、船期等权威数据，提升运输跟踪与口岸协同能力

---

## 1. 背景与价值

### 1.1 为什么对接官方平台
相比第三方免费 API，港口官方平台数据**权威、实时、完整**：
- 船舶到离港、集装箱在场/装卸状态
- 船期、箱货、VGM 等口岸数据
- 与海关单一窗口、口岸部门数据互通

### 1.2 目标港口与官方平台
| 港口 | 官方平台 | 数据能力 |
|------|----------|----------|
| **上海港** | 上港集团**港航纵横**（hb56.com）/ EDI 中心 | 船期、箱货、VGM、集装箱全程跟踪 |
| **青岛港** | 山东港口青岛港 **EDI 中心** | 集装箱动态、船舶状态、口岸作业 |
| **宁波港** | **宁波港口 EDI 中心**（npedi.com） | 船舶动态、集装箱状态、集卡动态 |
| （扩展） | 深圳/厦门/天津等港口 EDI 中心 | 同类型 |

---

## 2. 对接方式与前置条件

### 2.1 对接方式
港口官方平台通常提供**EDI 报文交换**（UN/EDIFACT 或 XML）与 **HTTP API** 两种方式：
| 方式 | 适用 | 特点 |
|------|------|------|
| EDI 报文交换 | 船司/大货代 | 数据批量、标准报文 |
| HTTP API | 中小货代 | 实时查询、JSON |
| 文件交换（SFTP） | 批量 | 到港/装卸报告 |

### 2.2 前置条件（需企业资质）
1. **企业注册**：在港口 EDI 平台注册企业账号。
2. **资质审核**：提供营业执照、货代资质等。
3. **对接协议**：签署数据服务/接口协议。
4. **报文规范**：获取港口报文规范文档（如 COARRI 装卸报告、COPRAR 到达报告）。
5. **密钥/证书**：获取接口密钥或数字证书。

> ⚠️ 具体流程以各港口 EDI 中心官方要求为准，部分需商务洽谈开通权限。

## 3. 对接架构设计

### 3.1 复用现有适配器模式
按港口拆分适配器，统一 `send()/query()` 接口，通过 `IntegrationConfig` 动态配置。

```
src/integrations/adapters/
├── portQingdao.js    # 青岛港
├── portShanghai.js   # 上海港
└── portNingbo.js     # 宁波港
```

### 3.2 适配器示例（`src/integrations/adapters/portQingdao.js`）
```js
// 青岛港 EDI 中心对接
// 负责集装箱状态、船舶动态查询与同步。
const axios = require('axios');
const crypto = require('crypto');
const code = 'port_qingdao';

function sign(cfg, payload) {
  const raw = JSON.stringify(payload) + (cfg.secret || '');
  return crypto.createHmac('sha256', cfg.secret || '').update(raw).digest('hex');
}

async function call(cfg, payload, action) {
  const url = `${cfg.baseUrl || ''}/api/${action}`;
  const headers = {
    'Content-Type': 'application/json',
    'X-Enterprise': cfg.enterpriseCode,   // 企业备案号
    'X-Sign': sign(cfg, payload),
    'X-Timestamp': Date.now(),
  };
  if (cfg.apiKey) headers['X-API-Key'] = cfg.apiKey;
  const resp = await axios.post(url, payload, { headers, timeout: 15000 });
  return resp.data;
}

async function send(cfg, payload) {
  return call(cfg, payload, 'container-status');   // 上报/同步
}

async function query(cfg, payload) {
  return call(cfg, payload, 'status');              // 查询集装箱/船舶状态
}

module.exports = { code, name: '青岛港 EDI', send, query };
```

### 3.3 多港口统一接口
对外提供统一查询接口，内部按港口路由到对应适配器：
```js
// src/services/portService.js
const { IntegrationClient } = require('../integrations');
const PORT_ADAPTER = {
  qingdao: 'port_qingdao',
  shanghai: 'port_shanghai',
  ningbo: 'port_ningbo',
};

async function queryContainer(portCode, containerNo) {
  const adapterCode = PORT_ADAPTER[portCode];
  if (!adapterCode) throw new Error(`不支持的港口: ${portCode}`);
  const client = await IntegrationClient.get(adapterCode);
  return client.query({ containerNo });
}
```

## 4. 数据模型扩展

### 4.1 港口数据表（新增 PortStatus）
```js
const PortStatus = sequelize.define('PortStatus', {
  id: { type: DataTypes.INTEGER, primaryKey: true, autoIncrement: true },
  portCode: { type: DataTypes.STRING(20) },        // qingdao / shanghai / ningbo
  containerNo: { type: DataTypes.STRING(30) },      // 箱号
  orderId: { type: DataTypes.INTEGER },             // 关联订单（可选）
  status: { type: DataTypes.STRING(50) },           // 在场/装卸/放行/离港
  location: { type: DataTypes.STRING(100) },        // 码头/堆场
  eventTime: { type: DataTypes.DATE },
  raw: { type: DataTypes.TEXT },                    // 原始回执
}, { timestamps: true, indexes: [{ fields: ['portCode', 'containerNo'] }] });
```

## 5. 接口设计

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /port/status | 查询集装箱/船舶状态（按港口） | read |
| POST | /port/sync | 手动触发某港口数据同步 | update |
| GET | /port/ports | 已配置港口列表 | read |

### 示例
```json
GET /api/port/status?port=qingdao&containerNo=COSU1234567
```

## 6. 数据同步策略

| 数据 | 同步方式 | 频率 |
|------|----------|------|
| 集装箱状态 | 定时轮询 + 订单触发 | 在途订单每 30 分钟 |
| 船舶动态 | 定时批量拉取 | 每日 |
| 船期 | 定时拉取缓存 | 每日 1-2 次 |
| 装卸/放行 | 事件驱动 | 实时 |

> 接入《控制性设计手册》定时任务，与免费 API 缓存策略一致，避免频繁调用。

## 7. 安全与合规

| 项 | 要求 |
|----|------|
| 密钥/证书 | 企业备案号、密钥加密存储 |
| 签名 | 请求签名 + 时间戳防重放 |
| 回执验签 | 防止伪造数据 |
| 企业资质 | 需港口 EDI 中心审核开通 |
| 数据合规 | 遵循港口数据服务协议，不对外泄露 |
| 日志 | 记录报文与回执（可追溯） |

## 8. 落地步骤

1. 向目标港口 EDI 中心提交企业资质申请，获取接口权限与报文规范。
2. 按港口新增适配器（`portQingdao/portShanghai/portNingbo`）。
3. `seed.js` 增加 IntegrationConfig 配置。
4. 新增 `PortStatus` 模型与 `/port/*` 接口。
5. 接入定时任务同步数据。
6. 运输跟踪页展示港口状态。
