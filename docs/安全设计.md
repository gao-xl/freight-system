# 安全设计

> 版本：v1.0
> 所属项目：《项目设计方案.md》阶段一 MVP
> 目标：针对现有系统安全缺口（CORS 全开、无权限生效、无输入校验、无限流等），提供完整的安全加固方案

---

## 1. 安全目标

为货代系统建立**分层防御**体系，覆盖认证、授权、传输、输入、数据、运维六个层面，满足中小企业私有化部署的安全基线。

## 3. 分层安全设计

### 3.1 认证层（Authentication）

**现状**：JWT 无状态鉴权，已实现。

**加固点**：
1. **强制密钥**：部署时必须设置 `JWT_SECRET`，无默认值兜底（生产拒绝启动）。
   ```js
   if (process.env.NODE_ENV === 'production' && !process.env.JWT_SECRET) {
     throw new Error('生产环境必须设置 JWT_SECRET');
   }
   ```
2. **Token 失效率**：支持登出/改密后使旧 token 失效（维护 token 黑名单或版本号）。
3. **过期策略**：12h 较短，建议拆分 `accessToken`（短）+ `refreshToken`（长，可选）。
4. **登录防爆破**：见 §3.4 限流。

### 3.2 授权层（Authorization）

**现状**：`requireRole` 未启用，无细粒度权限。
**方案**：按《权限控制设计.md》落地 **RBAC**，接口统一接入 `requirePermission(module, action)`。

### 3.3 传输层（Transport/HTTPS）

1. **强制 HTTPS**：Nginx 配置 301 跳转 + HSTS。
2. **安全响应头**（Nginx 或 helmet）：
   - `Strict-Transport-Security`
   - `X-Content-Type-Options: nosniff`
   - `X-Frame-Options: DENY`
   - `Content-Security-Policy`
3. 推荐使用 **helmet** 中间件：
   ```js
   const helmet = require('helmet');
   app.use(helmet());
   ```

### 3.4 输入校验与防护

1. **CORS 白名单**（替换全开）：
   ```js
   const cors = require('cors');
   app.use(cors({
     origin: process.env.CORS_ORIGIN ? process.env.CORS_ORIGIN.split(',') : false,
     credentials: true,
   }));
   ```
2. **入参校验**：引入 `joi` 或 `express-validator`，统一校验请求体/参数。
3. **SQL 注入防护**：禁用 `sequelize.query` 拼接，全部走 ORM 参数化（当前已满足）。
4. **XSS 防护**：前端转义，后端对富文本/备注字段做白名单。
5. **文件上传校验**（单证模块）：校验类型、大小、扩展名，禁止脚本文件，存储到非 web 目录。

### 3.5 数据安全

1. **数据库最小权限**：专用账号仅授所需库表权限。
2. **敏感字段加密**：密码已 bcrypt；API Key（对接配置）建议加密存储。
3. **备份加密**：云 RDS 备份启用加密。
4. **日志脱敏**：不打印密码、token、API Key。

### 3.6 运维安全

1. **速率限制**（防爆破）：
   ```js
   const rateLimit = require('express-rate-limit');
   app.use('/api/auth/login', rateLimit({
     windowMs: 15 * 60 * 1000,
     max: 20, // 15 分钟内最多 20 次
     message: { code: 429, message: '请求过于频繁，请稍后再试' },
   }));
   ```
2. **操作审计**：中间件记录关键写操作（谁、何时、改了哪个资源）。
3. **密钥管理**：环境变量/云密钥管理服务（KMS），不入代码库。
4. **依赖安全**：`npm audit` 定期检查漏洞。

## 4. 实现落地清单

### 4.1 依赖新增
```json
{
  "dependencies": {
    "helmet": "^7.1.0",
    "cors": "^2.8.5",
    "express-rate-limit": "^7.4.0",
    "joi": "^17.13.0"
  }
}
```

### 4.2 文件改动
| 文件 | 改动 |
|------|------|
| `src/server.js` | 加 helmet、CORS 白名单、全局限流 |
| `src/config/index.js` | 生产强制 JWT_SECRET、CORS 配置、限流参数 |
| `src/middleware/auth.js` | 启用 requirePermission（见权限设计） |
| `src/middleware/validate.js` | 新增入参校验中间件 |
| `src/middleware/audit.js` | 新增操作审计中间件 |
| `src/controllers/authController.js` | 登录限流、日志脱敏 |

### 4.3 环境变量新增
```ini
NODE_ENV=production
JWT_SECRET=<必填，高强度随机串>
CORS_ORIGIN=https://你的前端域名
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX=20
```
