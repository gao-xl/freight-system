## 1. 模块概述

### 1.1 定位
报价/询价是货代业务"**接单**"的起点：业务员收到客户询价 → 向承运人/协作方询价 → 综合成本+利润给客户出具报价单 → 客户确认后**转化为订单**。

### 1.2 业务角色
| 角色 | 动作 |
|------|------|
| 业务员（operator/sales） | 录入询价、编辑报价、发送给客户 |
| 经理（manager） | 审核报价、调整利润率 |
| 管理员（admin） | 配置费用类型字典、汇率 |

### 1.3 核心流程
```
客户询价 → 录入询价需求 → 生成报价单 → 填费用明细 → 计算总额/毛利
      → 审核 → 发送客户 → 客户确认 → [转化为订单] 
```

## 2. 数据模型设计

### 2.1 数据表（新增 2 张）

#### 2.1.1 Quotation（报价单头）

```js
const Quotation = sequelize.define('Quotation', {
  id: { type: DataTypes.INTEGER, primaryKey: true, autoIncrement: true },
  quoteNo: { type: DataTypes.STRING(40), allowNull: false, unique: true }, // 报价单号
  customerId: { type: DataTypes.INTEGER, allowNull: false },              // 客户
  type: { type: DataTypes.ENUM('import', 'export', 'transit'), defaultValue: 'export' },
  mode: { type: DataTypes.ENUM('sea', 'air', 'land', 'rail'), defaultValue: 'sea' },
  serviceType: { type: DataTypes.ENUM('fcl', 'lcl', 'charter', 'express'), defaultValue: 'fcl' },
  originPort: { type: DataTypes.STRING(50) },    // 起运港
  destPort: { type: DataTypes.STRING(50) },      // 目的港
  originPlace: { type: DataTypes.STRING(100) },  // 起运地
  destPlace: { type: DataTypes.STRING(100) },    // 目的地
  cargoDesc: { type: DataTypes.STRING(255) },    // 货物品名
  cargoWeight: { type: DataTypes.DECIMAL(12, 2) },
  cargoVolume: { type: DataTypes.DECIMAL(12, 2) },
  packageCount: { type: DataTypes.INTEGER },
  currency: { type: DataTypes.STRING(10), defaultValue: 'USD' },
  totalAmount: { type: DataTypes.DECIMAL(15, 2), defaultValue: 0 },      // 报价总额
  costAmount: { type: DataTypes.DECIMAL(15, 2), defaultValue: 0 },        // 预估成本
  profitAmount: { type: DataTypes.DECIMAL(15, 2), defaultValue: 0 },      // 预估毛利
  profitRate: { type: DataTypes.DECIMAL(6, 2), defaultValue: 0 },         // 毛利率 %
  status: { type: DataTypes.ENUM('draft', 'sent', 'confirmed', 'converted', 'expired', 'cancelled'), defaultValue: 'draft' },
  validUntil: { type: DataTypes.DATEONLY },       // 报价有效期
  remark: { type: DataTypes.TEXT },
}, { timestamps: true });
```

#### 2.1.2 QuotationItem（报价明细/费用项）

```js
const QuotationItem = sequelize.define('QuotationItem', {
  id: { type: DataTypes.INTEGER, primaryKey: true, autoIncrement: true },
  quotationId: { type: DataTypes.INTEGER, allowNull: false },  // 所属报价单
  name: { type: DataTypes.STRING(100), allowNull: false },     // 费用名称，如"海运运费"
  category: { type: DataTypes.ENUM('ocean_freight', 'air_freight', 'local_charge', 'customs_fee', 'document_fee', 'warehouse_fee', 'transport_fee', 'other'), defaultValue: 'other' },
  direction: { type: DataTypes.ENUM('revenue', 'cost'), defaultValue: 'revenue' }, // 收入项/成本项
  unit: { type: DataTypes.STRING(20) },        // 计费单位：箱/吨/CBM
  quantity: { type: DataTypes.DECIMAL(12, 2), defaultValue: 1 },
  unitPrice: { type: DataTypes.DECIMAL(15, 2), defaultValue: 0 },
  currency: { type: DataTypes.STRING(10), defaultValue: 'USD' },
  amount: { type: DataTypes.DECIMAL(15, 2), defaultValue: 0 },  // = quantity * unitPrice
  costPrice: { type: DataTypes.DECIMAL(15, 2), defaultValue: 0 }, // 成本价（来自供应商询价）
  supplierId: { type: DataTypes.INTEGER },      // 关联的成本来源供应商
  sortOrder: { type: DataTypes.INTEGER, defaultValue: 0 },
}, { timestamps: true });
```

### 2.2 关联关系
```
Customer 1 ── N Quotation 1 ── N QuotationItem
Quotation.belongsTo(Customer, { as: 'customer' })
QuotationItem.belongsTo(Quotation, { as: 'parent' })
Quotation.hasMany(QuotationItem, { as: 'items' })
```

### 2.3 金额计算规则
- 明细 `amount = quantity × unitPrice`
- `totalAmount = Σ(revenue 明细 amount)`
- `costAmount = Σ(cost 明细 amount)`
- `profitAmount = totalAmount - costAmount`
- `profitRate = (profitAmount / totalAmount) × 100`

> 金额计算在 **services 层**统一完成，避免散落各处。

## 3. API 设计

### 3.1 接口清单（前缀 `/api`）

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /quotations | 报价单列表（分页/筛选） | 认证用户 |
| GET | /quotations/:id | 报价单详情（含明细） | 认证用户 |
| POST | /quotations | 新建报价单 | operator/manager |
| PUT | /quotations/:id | 更新报价单（含明细批量） | operator/manager |
| DELETE | /quotations/:id | 删除报价单（仅草稿） | manager |
| POST | /quotations/:id/send | 标记"已发送" | operator |
| POST | /quotations/:id/confirm | 客户确认报价 | operator/manager |
| POST | /quotations/:id/convert-order | **转化为订单** | manager |
| GET | /quotations/stats | 报价统计（数量/金额/转化率） | manager |

**新建报价单**

## 4. 后端实现要点

### 4.1 文件结构（沿用现有分层）
```
src/
├── models/
│   ├── Quotation.js
│   └── QuotationItem.js
├── controllers/
│   └── quotationController.js
├── services/
│   └── quotationService.js      # 新增 services 层（金额计算/转订单）
├── routes/index.js              # 注册 /quotations 路由
```

### 4.2 关键逻辑
1. **报价单号生成**：`QT + yyyyMMdd + 流水号`（参考现有 `Order` 的 `orderNo` 规则）。
2. **金额计算**：在 `quotationService` 中统一计算头表汇总字段。
3. **事务保证**：新建/更新使用 `sequelize.transaction()`，保证头表+明细原子写入。
4. **转订单**：`convertOrder` 在事务内创建 `Order`，并将收入项明细落到 `FinanceRecord`（应收），成本项落到应付。
5. **状态机校验**：只有 `sent` 状态可 `confirm`，只有 `confirmed` 可 `convert-order`，只有 `draft` 可编辑/删除。

## 5. 前端设计

### 5.1 页面
| 页面 | 路由 | 功能 |
|------|------|------|
| 报价列表 | /quotations | 筛选、分页、状态标签、操作按钮 |
| 报价新建/编辑 | /quotations/edit(:id) | 表单：头信息 + 明细表格（动态增删行） |
| 报价详情 | /quotations/:id | 只读展示 + 打印/导出（可选） |

### 5.2 交互要点
- **明细表格**：费用项可增删行，录入单价/数量后实时计算金额与小计。
- **费用类型下拉**：对接 `category` 字典常量。
- **毛利实时预览**：顶部汇总卡片实时显示 总额/成本/毛利/毛利率。
- **操作按钮**：草稿→保存/发送；发送→确认；确认→转订单。
- **状态流转**：用 Element Plus 标签展示状态，按角色控制按钮显隐。
