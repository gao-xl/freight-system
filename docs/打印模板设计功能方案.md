# 打印模板设计功能方案

> 版本：v1.0
> 所属项目：《系统功能改进开发任务清单.md》A2（打印/导出）扩展
> 目标：提供**可配置的打印模板引擎 + 可视化设计器**，让用户在不改代码的前提下调整提单、发票、装箱单、对账单等单据的打印内容、字段与布局。

---

## 1. 背景与目标

### 1.1 为什么需要打印设计
现有打印/导出是"写死模板"，无法满足：
- 不同客户/航线对提单、发票的格式要求不同
- 需要增减打印字段、调整顺序、换 Logo、改页眉页脚
- 字段值格式（日期、金额、箱号）需自定义

### 1.2 核心能力
1. **模板管理**：按单据类型（提单/发票/装箱单/对账单...）维护多套模板，可复制、设默认。
2. **可视化设计器**：拖拽/勾选字段，实时预览，所见即所得。
3. **渲染引擎**：后端把"模板 JSON + 业务数据"渲染成 PDF/HTML。
4. **字段变量库**：从订单/订舱/报价/报关/财务等提取可打印字段。

---

## 2. 功能范围

| 模块 | 能力 |
|------|------|
| 模板管理 | 增删改查、复制、设默认、按单据类型分组 |
| 打印设计器 | 区块配置、字段绑定、显隐、排序、样式、Logo/页眉页脚 |

## 3. 数据模型

### 3.1 PrintTemplate（打印模板）
```js
const PrintTemplate = sequelize.define('PrintTemplate', {
  id: { type: DataTypes.INTEGER, primaryKey: true, autoIncrement: true },
  name: { type: DataTypes.STRING(100), allowNull: false },        // 模板名
  docType: { type: DataTypes.ENUM('bl','invoice','packing_list','quotation','customs','statement','order','settlement'), allowNull: false }, // 单据类型
  content: { type: DataTypes.TEXT },       // 模板 JSON（区块定义）
  isDefault: { type: DataTypes.BOOLEAN, defaultValue: false },     // 是否默认模板
  pageSize: { type: DataTypes.STRING(20), defaultValue: 'A4' },   // A4/A5/Letter
  logoUrl: { type: DataTypes.STRING(255) },  // 公司 Logo
  header: { type: DataTypes.TEXT },          // 自定义页眉（文本/HTML）
  footer: { type: DataTypes.TEXT },          // 自定义页脚
  remark: { type: DataTypes.TEXT },
}, { timestamps: true });
```

## 4. 字段变量库设计

### 4.1 字段来源与变量语法
- 语法：`{{ 数据源.字段 }}`，如 `{{ order.orderNo }}`、`{{ booking.vesselName }}`。
- 聚合嵌套：`{{ order.customer.name }}`、`{{ quotation.totalAmount }}`。
- 格式化：`{{ order.etd | date }}`、`{{ order.totalAmount | money USD }}`。

### 4.2 字段分组（按单据类型加载）
| 单据类型 | 可用数据源 |
|----------|-----------|
| bl 提单 | order + booking + customer |
| invoice 发票 | order + quotation + quotation.items |
| packing_list 装箱单 | order + 货物数据 |
| quotation 报价单 | quotation + quotation.items |
| customs 报关单 | customs + order |
| statement 对账单 | finance（按订单/客户汇总） |
| order 订单操作单 | order + customer |
| settlement 结算单 | finance + order |

### 4.3 字段元数据
```js
// 字段定义（供设计器左侧字段库展示）
{ key: 'order.orderNo', label: '订单号', group: '订单', type: 'string' }
{ key: 'order.totalAmount', label: '总金额', group: '订单', type: 'money' }
{ key: 'order.etd', label: '预计发运', group: '订单', type: 'date' }
```

## 5. 渲染引擎设计

```
模板 JSON + 业务数据JSON
        │
        ▼
resolveFields()  → 按字段变量从数据对象取值 + 格式化
        │
        ▼
renderHTML()     → 生成结构化 HTML（区块/表格/页眉页脚）
        │
        ▼
toPDF()          → HTML → PDF
```

### 5.1 方案选型
| 方案 | 优点 | 缺点 | 建议 |
|------|------|------|------|
| puppeteer（HTML→PDF） | 布局灵活、支持 CSS/复杂表格 | 依赖 Chromium，较重 | **推荐**（复杂单据） |
| pdfkit（代码布局） | 轻量 | 复杂布局编码量大 | 适合简单单据 |
| 前端 window.print() | 零后端依赖 | 依赖浏览器打印设置 | 适合快速打印 |

> 建议：**后端 puppeteer 渲染 PDF**（保证一致性），同时提供 HTML 预览地址供设计器使用。

### 5.2 服务 `src/services/printService.js`
```js
async function render(templateId, bizData) {
  const tpl = await PrintTemplate.findByPk(templateId);
  const resolved = resolveFields(JSON.parse(tpl.content), bizData);
  const html = renderHTML(tpl, resolved);
  return { html, pdf: await htmlToPDF(html, tpl.pageSize) };
}
```

## 6. 打印设计器（前端）

### 6.1 页面结构（`/system/print-templates`）
```
┌──────────────┬──────────────────────┬──────────────┐
│ 左：字段库     │  中间：画布预览       │  右：属性面板  │
│ 订单字段       │  A4 白纸            │  选中区块属性  │
│ 订舱字段       │  区块实时渲染        │  字段显隐/排序│
│ 客户字段       │  所见即所得          │  样式/对齐    │
│ ...           │                      │  页眉页脚     │
└──────────────┴──────────────────────┴──────────────┘
```

### 6.2 交互能力
- 从左侧字段库**拖拽/勾选**加入指定区块。
- 区块**增删、排序、显隐**（标题、Logo、单据信息、货物明细表、签署区、页脚）。
- 字段**显隐、顺序、标签、格式化**（日期/金额）。
- **Logo 上传**、页眉页脚文本编辑。
- **实时预览**：设计态用示例数据渲染；可绑定真实单据预览。
- 保存为模板，设默认模板。

### 6.3 技术要点
- 字段库由后端 `GET /print-templates/fields/:docType` 提供（读字段元数据）。
- 画布用 iframe 内嵌渲染出的 HTML，保证与最终 PDF 一致。
- 组件化：`TemplateDesigner.vue`（主）+ `FieldLibrary.vue` + `CanvasPreview.vue` + `PropPanel.vue`。

## 7. API 设计

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /print-templates | 模板列表（按 docType 过滤） | print:read |
| GET | /print-templates/:id | 模板详情 | print:read |
| POST | /print-templates | 新增模板 | print:write |
| PUT | /print-templates/:id | 更新模板 | print:write |
| POST | /print-templates/:id/copy | 复制模板 | print:write |
| DELETE | /print-templates/:id | 删除模板 | print:write |
| PUT | /print-templates/:id/default | 设为默认 | print:write |
| GET | /print-templates/fields/:docType | 字段库 | print:read |
| POST | /print-templates/:id/preview | 用示例/真实数据预览 | print:read |
| GET | /print/:docType/:bizId?template=id | 渲染并下载 PDF | print:read |

> 权限编码：新增 `print` 模块（read/write），并入《权限控制设计.md》RBAC。

## 8. 与打印/导出（A2）集成

- A2 的"打印/导出"改为**默认模板渲染**：各处"打印"按钮调用 `GET /print/:docType/:bizId`，使用该单据类型的默认模板。
- 用户可在打印页选择"使用其他模板"或"编辑模板"。
- 对账单/订单/报价等均接入模板引擎，替换写死模板。

## 9. 安全与实现要点

| 项 | 要求 |
|----|------|
| 模板权限 | 仅 admin/manager 可设计，operator 只读使用 |
| HTML 注入 | 页眉页脚文本做转义，防 XSS |
| 数据合规 | 打印数据仅取当前用户有权限的单据 |
| 渲染性能 | PDF 渲染缓存（同模板+同数据短时复用） |
| 存储 | 模板 JSON 存 TEXT，Logo 走附件上传（复用任务 A1） |
