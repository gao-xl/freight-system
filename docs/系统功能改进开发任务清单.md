# 系统功能改进开发任务清单

> 版本：v1.0
> 依据：《系统功能缺口与优化建议.md》（含"按团队角色分析"）改进路线，细化为可执行开发任务

---

## 0. 现状基础盘点（避免重复建设）

| 项 | 现状 | 影响 |
|----|------|------|
| 单证附件 | `Document` 已有 `filePath` 字段 | 附件上传只需补上传接口 + 前端组件，无需改模型 |
| 财务字段 | `FinanceRecord` 已有 `rate/dueDate/invoiceNo/paidAmount` | 对账/开票/核销有字段基础 |
| 操作日志 | `middleware/audit.js` 已存在但仅 `console.log` | 只需补落库 + 查询接口 |
| 定时任务 | `package.json` 无 `node-cron` | 预警需新增依赖 |
| 文件上传 | 无 `multer` | 附件/导出需新增依赖 |

## 5. 任务依赖关系

```
A1(A2) ──→ B1
A3 ──────→ B2 ──→ B3
B4 ──→ B6 ──→（B1 经营指标）
A2 ──→ B7（单证套打）
A3 ──→ B5（超期未跟进预警）
B4 ──→ B8（放单校验应收结清）
A3/B3/B4 ──→ A4（待办中心聚合）
C1 ──→（依赖 B2/B3 时间线）
C2 ──→（依赖 B3 节点）
C3 ──→（独立，可并行）
C4 ──→（依赖 B4）
C5 ──→（独立）
```

### 5.1 B5/B6/B7/B8 依赖明细

| 任务 | 前置依赖 | 依赖说明 | 阻塞项 |
|------|----------|----------|--------|
| **B5 客户跟进 CRM** | A3（预警） | 超期未跟进提醒复用 A3 预警引擎；若 A3 未做，B5 可先做跟进 CRUD，提醒后补 | A3 未完成则"超期未跟进预警"延后，不影响 CRUD |
| **B6 单票成本/毛利** | B1（经营指标）、B4（对账/核销） | 毛利汇总复用 B1 汇总框架；收入/成本归集依赖 B4 对账数据口径 | B4 未完成则成本归属口径不完整，毛利可能不准 |
| **B7 单证状态机+套打** | A2（打印模板）、B3（订单节点数据） | 套打直接调用 A2 模板引擎；自动生成单证内容依赖 B3 订单节点数据 | A2 未完成则无法套打输出（可先做状态机与草稿生成） |
| **B8 放单控制** | B4（对账/核销） | 放单前校验应收结清依赖 B4 核销数据；审批流依赖《二次开发扩展空间设计》 | B4 未完成则无法准确判断结清，放单控制失效 |

**DAG 关键路径**：`A2 → B7`、`B4 → B6`、`A3 → B5`、`B4 → B8`，B5/B6/B7/B8 相互独立可并行（B6/B8 同依赖 B4）。
